# マシン詳細画面

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 対応 Issue | [#22: フロント／マシン詳細画面の機能設計](https://github.com/Undanomi/SLSG/issues/22) |
| ルート | `/machines/[machineId]` |
| アクセス条件 | 認証必須。対象マシンを閲覧できない場合は、権限なしまたは対象なしの状態を表示する。 |
| 目的 | マシンの情報を確認し、フラグ回答、成果物ダウンロード、誘導問題作成を行えるようにする。 |

## 表示要素

- マシン一覧と同じ構成の、アイコン・マシン名・モックデータの概要からなるページ見出し
- 見出しの右側に置く「ダウンロード」ボタンと「誘導問題」ボタン
- マシン説明カード。説明文、公開範囲、難易度、テーマ、作成者、作成日を表示する。
- ユーザーフラグ入力欄と判定ボタン
- システムフラグ入力欄と判定ボタン
- 各フラグの解答状態と判定結果
- 「ダウンロード」ボタン。ダウンロード可能な状態でのみ実行可能にする。
- 「誘導問題」ボタン。作成中・作成結果・失敗を表示する領域は、誘導問題機能の実装時に追加する。
- マシン一覧へ戻る導線

## 操作と遷移

| 操作 | 結果 |
| --- | --- |
| 戻る | `/machines` へ遷移する。 |
| ユーザーフラグを送信 | 判定結果と回答済み状態を更新する。 |
| システムフラグを送信 | 判定結果と回答済み状態を更新する。 |
| フラグ入力欄で Enter を押す | 判定を送信しない。判定は明示的に「判定する」ボタンを選択した場合だけ実行する。 |
| ダウンロードを選択 | ブラウザで成果物のダウンロードを開始する。ダウンロード方式は成果物ダウンロード設計に従う。 |
| 誘導問題を作成 | 誘導問題の作成を開始し、完了後に結果を表示する。 |

## 画面状態

| 状態 | 表示・操作 |
| --- | --- |
| 読み込み中 | 詳細領域に読み込み中の表示を出す。 |
| ダウンロード可能 | ダウンロードボタンを有効化する。 |
| フラグ未回答／不正解／正解 | 入力欄と判定結果を状態に応じて表示する。正解後も他方のフラグは独立して回答できる。 |
| 対象なし・権限なし | 詳細情報やフラグを表示せず、一覧へ戻る導線を提示する。 |
| 誘導問題作成中・成功・失敗 | 誘導問題 UI の領域内で状態を表示し、失敗時は再実行できるようにする。 |

## 誘導問題作成 UI の扱い

誘導問題は、ページ見出しの右端に置く独立した操作ボタンとして実装する。フラグ回答、ダウンロード、詳細情報の表示に依存させない。作成中・作成結果・失敗の UI は、誘導問題機能の実装時に追加する。

## 実装時の責務

- 初期表示でマシンの表示情報とフラグ回答状態を取得する。
- フラグ送信ごとに、該当する入力欄の送信中・結果・エラーを独立して扱う。入力欄で Enter を押しただけでは送信しない。
- フラグの正解値、ダウンロード URL、誘導問題の生成方式は画面に持たせない。
