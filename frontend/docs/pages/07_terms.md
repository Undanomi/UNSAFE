# 利用規約画面

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 対応 Issue | なし（共通ページ） |
| ルート | `/terms` |
| アクセス条件 | 公開。認証不要。 |
| 目的 | 演習の対象、禁止行為、免責事項などの利用条件を確認できるようにする。 |

## 表示要素

- サービスの目的と利用条件
- 演習環境の安全な利用
- 禁止行為
- 生成内容と免責事項
- 利用制限とサービスの中断
- プライバシーポリシーへの案内と規約の変更方針
- 最終更新日、目次、ログイン画面へ戻る導線

## 操作と遷移

| 操作 | 結果 |
| --- | --- |
| 目次を選択 | 対応する条項へ移動する。 |
| 「ログインへ戻る」を選択 | `/login` へ遷移する。 |
| 「プライバシーポリシー」を選択 | `/privacy` へ遷移する。 |

## 実装時の責務

- 本文は現在のサービスと運営方針に沿った利用条件を表示する。
- 攻撃・検証の対象を、管理する演習用マシンまたは明示的な許可を得た範囲に限定する。
- 個人情報の説明はプライバシーポリシーに集約する。
- 利用制限の記載は運営方針を示すもので、自動検知や管理画面の提供を示すものではない。
