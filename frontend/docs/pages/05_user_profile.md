# ユーザー情報画面

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 対応 Issue | [#21: フロント／ユーザー情報画面の機能設計](https://github.com/Undanomi/SLSG/issues/21) |
| ルート | 自分のプロフィールは `/profile`、作成者の公開プロフィールは `/users/[userId]` |
| アクセス条件 | 認証必須。未認証の場合は `/login` へ遷移する。 |
| 目的 | 利用者自身のプロフィールと、作成済み・解答済みマシンを確認・編集できるようにする。作成者の公開プロフィールでは同じ情報を閲覧専用で表示する。 |

## 表示要素

- ユーザー名
- プロフィール画像
- 自己紹介
- プロフィール編集ボタン
- 作成済みマシン一覧
  - マシン名
  - 作成日
  - 一定の表示高さを超える場合はカード内でスクロールする
- 解答済みマシン一覧
  - マシン名
  - 作成日
  - 解答日
  - 一定の表示高さを超える場合はカード内でスクロールする
- 作成者の公開プロフィールでは、マシン一覧へ戻る導線

## 操作と遷移

| 操作 | 結果 |
| --- | --- |
| 公開プロフィールで戻る | `/machines` へ遷移する。自分のプロフィール（`/profile`）には戻る導線を表示しない。 |
| マシン一覧の作成者名を選択 | `/users/[userId]` へ遷移する。 |
| 作成済みまたは解答済みマシンを選択 | `/machines/[machineId]` へ遷移する。 |
| プロフィール編集を開始 | ユーザー名、自己紹介、アイコンの表示方法を編集できる状態にする。アイコンは Google アカウントの画像または名前のイニシャルから選ぶ。 |
| 編集内容を保存 | 反映結果を表示し、成功時は表示中のプロフィールを更新する。 |
| 編集を取り消す | 編集前の表示へ戻す。 |

## 画面状態

| 状態 | 表示・操作 |
| --- | --- |
| 読み込み中 | プロフィールとマシン一覧に読み込み中の表示を出す。 |
| 表示 | ユーザー情報、作成済み、解答済みを表示する。各一覧は空状態を個別に表示する。 |
| 編集中 | ユーザー名、自己紹介、プロフィール画像を編集可能にし、保存・取消操作を表示する。 |
| 保存中 | 重複保存を防ぐため保存操作を無効化する。 |
| 保存失敗 | 編集内容を保持したままエラーを表示し、再試行できるようにする。 |
| 他ユーザー表示 | `/users/[userId]` ではプロフィールとマシン一覧を閲覧専用で表示し、編集操作は表示しない。 |

## 実装時の責務

- 初期表示でログイン中の利用者のプロフィール、作成済みマシン、解答済みマシンを取得する。
- 作成済みマシンはビルド完了済み（`status = ready`）だけを表示する。作成済み・解答済みマシンは削除済みを除き、公開済みまたは閲覧者自身が作成したマシンだけを表示する。解答済みには全フラグを正解した他人のマシンだけを含める。作成済みは作成日の新しい順、解答済みは最後のフラグの正解日の新しい順に並べる。
- 編集中の入力値、アイコンの表示方法、保存中・保存失敗の状態は Client Component で扱う。
- 閲覧者の識別子は認証情報から取得する。`/users/[userId]` の表示対象は URL の `userId` で指定する。プロフィールの保存先や画像保存方式は画面の責務に含めない。
- `/profile` はログイン中の利用者だけが編集できるようにし、`/users/[userId]` は指定された作成者の公開情報を閲覧専用で表示する。
