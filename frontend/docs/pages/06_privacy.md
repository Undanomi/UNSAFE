# プライバシーポリシー画面

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 対応 Issue | なし（共通ページ） |
| ルート | `/privacy` |
| アクセス条件 | 公開。認証不要。 |
| 目的 | 利用者情報の取り扱いと問い合わせ先を確認できるようにする。 |

## 表示要素

- サービス名
- プライバシーポリシーの本文
- 最終更新日
- 問い合わせ先
- ログイン画面へ戻る導線

## 操作と遷移

| 操作 | 結果 |
| --- | --- |
| 「ログインへ戻る」を選択 | `/login` へ遷移する。 |

## 実装時の責務

- 本文は法務・運用方針の確定内容を表示する。
- Google OAuth を提供する場合は、OAuth 同意画面に登録するプライバシーポリシー URL と一致させる。
