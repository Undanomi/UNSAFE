# マシン一覧画面

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 対応 Issue | [#24: フロント／マシン一覧画面の機能設計](https://github.com/Undanomi/SLSG/issues/24) |
| ルート | `/machines` |
| アクセス条件 | 認証必須。未認証の場合は `/login` へ遷移する。 |
| 目的 | 利用者が作成したマシンと公開済みマシンを確認し、詳細表示または新規作成を開始できるようにする。 |

## 表示要素

- ページ見出し
- 「マシン作成」ボタン
- マシン一覧
  - マシン名
  - 作成者アイコンと作成者名（`/users/[userId]` へのリンク）
  - 作成日
  - 公開状態
  - マシンを特定するための ID
- ページング。1ページあたり10件を初期値とし、複数ページの場合に現在ページと前後ページへの移動を表示する。
- 空状態の案内と「マシン作成」導線
- ユーザー情報画面への導線

一覧では、ログイン中の利用者が作成したマシンと、他の利用者が公開したマシンを取得して表示する。各行では公開状態を表示し、利用者が自分のマシンと公開済みマシンを区別できるようにする。

## 操作と遷移

| 操作 | 結果 |
| --- | --- |
| 「マシン作成」を選択 | `/machines/chat` へ遷移し、新規チャットを表示する。 |
| 一覧のマシンを選択 | `/machines/[machineId]` へ遷移する。 |
| 一覧の作成者を選択 | `/users/[userId]` へ遷移する。 |
| ページを切り替える | 指定したページの一覧を表示する。 |
| ユーザー情報を選択 | `/profile` へ遷移する。 |

## 画面状態

| 状態 | 表示・操作 |
| --- | --- |
| 読み込み中 | 一覧部分に読み込み中の表示を出す。 |
| 一覧あり | マシン名、作成者、作成日を行ごとに表示し、各行を選択できるようにする。複数ページの場合はページングを表示する。 |
| 空 | 自分が作成したマシンおよび公開済みマシンがないことを示し、「マシン作成」導線を表示する。 |
| 取得失敗 | 失敗を表示し、再読み込みできるようにする。 |

## 将来機能

検索、絞り込み、並び替えは Issue #24 で任意機能とされているため、初期実装には含めない。必要になった時点で、検索条件、並び順、URL パラメーターの扱いをこの設計書へ追記する。

DB連携後のページングでは、ページ番号を `?page=2` のようなURLクエリで表現し、ページ遷移ごとに該当ページの一覧を取得する。`page` は1始まりとし、未指定または不正な値は1ページ目として扱う。検索条件・絞り込み・並び順を追加する場合も同じクエリに保持し、条件を変更した場合は1ページ目へ戻す。

## 実装時の責務

- 初期表示で、本人が作成したマシン一覧と公開済みマシン一覧を取得し、一覧表示用にまとめる。
- マシン名・作成者名の選択とページ遷移を画面側で扱う。
- 一覧データの所有権確認、検索・並び替えの実現方法、下流サービスとの通信は画面の責務に含めない。
