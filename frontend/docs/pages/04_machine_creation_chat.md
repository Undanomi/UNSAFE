# マシン作成チャット画面

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 対応 Issue | [#25: フロント／チャット画面の機能設計](https://github.com/Undanomi/SLSG/issues/25) |
| ルート | `/machines/chat`、`/machines/chat/[sessionId]` |
| アクセス条件 | 認証必須。未認証の場合は `/login` へ遷移する。 |
| 目的 | AI との会話でマシン作成条件を収集し、マシン生成・ビルドを開始する。 |

## ルートごとの役割

| ルート | 役割 |
| --- | --- |
| `/machines/chat` | 新規チャットを直接表示する。会話領域は未入力のステップ1から始め、サイドバーで既存チャットを選択できる。 |
| `/machines/chat/[sessionId]` | BFF が保存した指定の作成セッションの会話と作成状態を表示する。再読み込み時も同じ会話を復元する。 |

新規チャットは `/machines/chat` を開いた時点で表示する。サイドバーには BFF から取得した既存の作成セッションのみを表示し、入力途中の新規チャットは追加しない。マシン名の確定時に AI サーバーのセッションとPostgreSQLの `chat_sessions` レコードを作成し、一覧へ反映する。既存チャットを選択した場合は対応する `/machines/chat/[sessionId]` へ遷移する。会話履歴を持たないマシンは、チャット選択の対象にしない。ブラウザの永続ストレージは会話状態の保存に使用しない。

## 表示要素

- チャットのサイドバー
  - 全認証画面で共有する固定サイドバー下部の「チャット一覧」トグル
  - 既存の作成セッション一覧
- 会話領域
  - 固定された質問文を表示する AI メッセージ
  - 確定済み回答を表示する利用者メッセージ
  - 質問と回答を時系列で残す会話履歴
  - 現在の入力ステップと、進行状況
- 入力領域
  - 会話履歴の下に置く入力コンポーザー
  - 現在の質問に対応する自由入力または選択肢と、次の質問へ進むボタン
- 会話操作
  - 確定済みの各利用者メッセージ下部に表示するペンアイコンからの再編集
  - 作成中チャットの中止または破棄
- 作成操作
  - 必要な条件がそろった後に表示する「マシンを作成」ボタン
  - 生成・ビルドの受付状態と失敗状態

## 固定入力フロー

質問の順序と入力形式は固定とする。AI が質問順や入力形式を動的に決める構成にはしない。

| ステップ | 質問・入力 | 入力形式 | 分岐・作成可能状態 |
| --- | --- | --- | --- |
| 1 | マシン名を入力してください | 自由入力。40文字以内。 | 入力後にステップ2へ進む。 |
| 2 | 公開範囲を教えてください | `非公開` または `公開` の選択。 | 選択後にステップ3へ進む。 |
| 3 | どのようなシナリオのマシンを作成しますか？ | 500文字以内の文章入力と、文章形式の例文選択肢。 | 入力または選択後にステップ4へ進む。 |
| 4 | 難易度を入力してください | `Very Easy`、`Easy`、`Medium`、`High` の選択。 | 必須項目がそろうため、ここでマシンを作成できる。詳細設定を続ける場合はステップ5へ進む。 |
| 5 | ユーザーフラグを用意しますか | `はい` または `いいえ` の選択。 | `はい` の場合はステップ6へ、`いいえ` の場合はステップ7へ進む。 |
| 6 | ユーザーフラグを取得するのに必要な情報を、できる限り詳細に入力してください | 自由入力。 | 入力後にステップ7へ進む。 |
| 7 | システムフラグを用意しますか | `はい` または `いいえ` の選択。 | `はい` の場合はステップ8へ、`いいえ` の場合は作成可能状態へ進む。 |
| 8 | システムフラグを取得するのに必要な情報を、できる限り詳細に入力してください | 自由入力。 | 入力後に作成可能状態へ進む。 |

ステップ4以降は、収集済みの内容を確認できるようにする。ステップ4で作成する場合はフラグに関する設定を含めず、ステップ5〜8まで進めた場合は選択・入力されたフラグ設定を含めて作成する。
ステップ3の文章はAIへ渡すシナリオ要望として扱う。公開マシンの検索・分類用タグは入力させず、完成したシナリオ本文と攻撃グラフからAIが1〜5個を自動生成する。

## 操作と遷移

| 操作 | 結果 |
| --- | --- |
| サイドバーで新規チャットを開始 | `/machines/chat` を表示し、未入力のステップ1から入力できるようにする。 |
| 既存チャットまたはマシンを選択 | 対応するセッション ID を解決し、`/machines/chat/[sessionId]` へ遷移する。 |
| 現在の質問に回答して次へ進む | 入力を検証し、固定フローに従って次のステップと収集済み条件を更新する。 |
| マシン名を確定してステップ2へ進む | 入力内容を検証し、AI サーバーのセッションとPostgreSQLの会話状態を作成して次の質問を表示する。 |
| 確定済み回答のペンアイコンを選択 | 選択した回答だけを再入力・再選択する UI を表示し、更新後の回答を会話履歴と入力内容の概要へ反映する。 |
| チャットを中止・破棄 | 画面内フィードバックを表示せず、`/machines` へ戻る。 |
| ステップ4でマシンを作成 | フラグ設定なしで生成・ビルドを要求し、対象マシンを特定できた後に `/machines/[machineId]` へ遷移する。 |
| ステップ5〜8の完了後にマシンを作成 | 選択・入力したフラグ設定を含めて生成・ビルドを要求し、対象マシンを特定できた後に `/machines/[machineId]` へ遷移する。 |

## 画面状態

| 状態 | 表示・操作 |
| --- | --- |
| 新規チャット | 未入力のステップ1と、サイドバーの既存チャット一覧を表示する。 |
| セッション読み込み中 | 初回アクセス、既存チャットの切り替え、マシン名確定後の遷移では、チャット画面の背景・サイドバー・会話パネル・入力欄の配置を保つ骨格表示を出す。未取得のマシン名、会話、進捗は表示しない。 |
| 入力中 | 確定済みの質問・回答履歴、現在のAI質問、入力コンポーザー、進行状況を表示する。送信中は同じ回答を重複送信できない。 |
| ステップ4完了 | 基本項目がそろったことを表示し、「マシンを作成」と「詳細設定を続ける」を選択できるようにする。 |
| ステップ5〜8 | フラグ設定の選択・詳細入力を表示する。`いいえ` を選択した詳細入力ステップは表示しない。 |
| 詳細設定完了 | 最終的な収集内容と「マシンを作成」ボタンを表示する。 |
| 生成・ビルド受付中 | 作成操作の重複を防ぎ、受付状態を表示する。 |
| 失敗 | 内部エラーの詳細を表示せず、会話の継続または再試行を可能にする。 |
| 無効なセッション・権限なし | 会話を表示せず、`/machines/chat` または `/machines` へ戻る導線を提示する。 |

## 実装時の責務

- `/machines/chat` および `/machines/chat/[sessionId]` の初期表示で、BFF が保存した選択中セッション、サイドバー一覧、固定フロー上の現在ステップ、収集済み条件、生成状態を取得する。
- 入力欄、ステップ遷移、入力エラー、送信中、表示内容の更新は Client Component で扱う。
- セッションの作成・所有権確認、入力内容の保存、生成・ビルド要求は Next.js の BFF に委譲する。
- 完了済みチャットや `ready` のマシンに対する設定保存・生成要求は、画面の状態に関係なく BFF 側で拒否する。失敗・中止した生成の再試行は許可する。
- 会話状態はPostgreSQLの `chat_sessions` に保存し、AI サーバーの接続先はサーバー専用環境変数 `AI_SERVER_URL` で指定する。
- シナリオ生成の SSE は Route Handler で AI サーバーから中継し、ブラウザへ AI サーバーの URL や認証用ユーザー ID を公開しない。
